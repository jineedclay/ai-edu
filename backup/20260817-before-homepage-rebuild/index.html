ABOUT DCLAY

기술보다 먼저,
현장을 이해합니다

DClay는 생성형 AI와 데이터를 조직의 실제 업무와 연결하는 실무교육 전문 브랜드입니다.

교육 대상의 경험, 조직의 환경, 교육 이후의 활용까지 고려해 듣는 교육을 넘어 직접 써보는 교육을 설계합니다.

01

현장 중심

교육 대상과 조직의 실제 상황에서 출발합니다.

02

실습 중심

설명보다 직접 실행하고 결과를 만드는 시간을 중시합니다.

03

적용 중심

교육 이후에도 업무와 일상에서 활용할 수 있도록 설계합니다.
